# Security Policy

## Supported versions

Sticker UI is currently in beta. Security fixes are applied to the latest
published beta and carried forward to the next release. Older prereleases are
not maintained.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue, discussion, pull
request, or social post.

Use GitHub's private vulnerability reporting page:

<https://github.com/cixiangtao/sticker-ui/security/advisories/new>

If private reporting is temporarily unavailable, open a public issue that asks
the maintainer to establish a private contact channel. Do not include technical
details, proof-of-concept code, credentials, or affected user data in that
issue.

Include the affected package version, impact, reproduction conditions, and any
known mitigation in the private report. The maintainer will coordinate
validation, remediation, release timing, and public disclosure through the
private advisory.
