# Support

English | [简体中文](SUPPORT.zh-CN.md)

## Usage help

Start with the [live component documentation](https://sticker-ui.cixiangtao.workers.dev/)
and search [existing issues](https://github.com/cixiangtao/sticker-ui/issues)
for the component, error message, or installation mode involved.

If the problem remains, open an issue through the repository issue chooser and
include:

- the installed Sticker UI version;
- whether the npm package or source Registry is being used;
- React, Tailwind CSS, package manager, and browser versions;
- a minimal reproduction or repository;
- expected and actual behavior.

## Bug reports and feature requests

Use the structured bug or feature form in the
[issue chooser](https://github.com/cixiangtao/sticker-ui/issues/new/choose).
Public issues are handled on a best-effort basis; the project does not provide
a response-time or compatibility SLA.

## Security

Do not use public support channels for vulnerabilities. Follow
[SECURITY.md](SECURITY.md).
